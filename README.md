## Contents

- **ISTQB Checkpoints** – Study and revision materials covering ISTQB Foundation Level topics.
- **Test Cases** – Sample test cases for various applications.
- **Bug Reports** – Defect logs and issue tracking documents.
- **Test Execution Reports** – Evidence of executed test cases and results.
- **Deployment Documentation** – Sample deployment plans and implementation documents.
- **API Documentation** – Postman-related testing documentation.

## Purpose

This repository serves as:

- A collection of QA artifacts for reference.
- A portfolio showcasing software testing documentation and best practices.
